No audio assets are included by this preparation task. These are dependencies for future integration, not implemented features or placeholder sounds.

When delivered, record filename, author, source URL where applicable, exact license, permission for redistribution, required attribution, modifications, format, duration, channels, and size. Keep any required license text in `docs/licenses/`. Original recordings also need an authorship/provenance record; do not assume a pack is redistributable because it is downloadable.

Use short, optimized, comfortably levelled files and consistent names. Choose shipped formats after checking native macOS and Windows playback; retain original production masters outside the runtime bundle. Bundle only the necessary exports locally. No sound-pack marketplace, runtime downloads, or unlicensed substitutes.

T-25 can establish the manager and preferences with synthetic test buffers, but synthetic buffers do not satisfy the shipped asset criteria. T-26/T-27/T-31 cannot be completed without their actual assets and licence evidence. None of these dependencies prevents documentation, token work, or a muted app from functioning.
