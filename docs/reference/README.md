# Original design references

These are the product owner's two original Main Chat mockups, retrieved from that referenced conversation on November 3, 2026:

- `terminal-workspace-mockup.png`: rail, compact tools panel, dominant journal workspace.
- `arlecchino-brand-mockup.png`: dark surfaces, mint outline, italic `t >` identity.

The accepted [design system](../UI-DESIGN-SYSTEM-v0.1.md) preserves their proportions and atmosphere while specifying readable upright body text, a left-aligned writing column, New Entry in the third rail slot, keyboard focus, and save-error visibility. Typography recommendations and supporting colors are accepted design guidance, not a claim that the mockup font was conclusively identified.
